# Rounded SA identity

The approved SA 03 concept is recreated as a small vector monogram in `public/brand-sa.svg`: amber S (#FFB237), warm ivory A (#F6E9D3), rounded outlines and transparent background. The shared Brand component uses this mark with a Raleway ExtraBold HTML wordmark, using the existing locally hosted variable font. Both header and footer use the same identity, and the browser icon references the same SVG.

The brand retains amber/ivory. Sidebar navigation uses white inactive labels and icons, with amber active, hover and keyboard focus states. Icon and label inherit the same color. Its bottom shield is green (#65C78B). Countries uses a pinned-map icon; World Map retains the globe. These choices also apply to the mobile drawer. The global Encre & indigo theme, content, cards, buttons and their accent colors are preserved. The sidebar caption DISCOVER is removed; its expand/collapse and mobile close controls remain accessible.
